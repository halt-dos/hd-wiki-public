# KB: 1008
----------

### Securing File Uploads in Web Applications

#### **Problem Statement**

Web applications that accept file uploads are a common attack surface. Attackers often attempt to upload malicious code, viruses, or malware as file attachments during multi-part form submissions. Without proper controls, these files can reach the backend and lead to web-shell deployment, malware infection, or data compromise.

#### **Overview**

Haltdos WAF protects file uploads using a layered approach:

- **Extension-based blocking** — Restrict dangerous file types at the Web Policy level.
- **Per-form validation** — Allow only specific file extensions and sizes for individual upload forms.
- **Request size limits** — Reject oversized uploads before they reach the backend.
- **Antivirus scanning** — Inspect uploaded file content using the built-in scanner or an external ICAP server.

Blocked uploads are dropped by the WAF and recorded on the [Incidents](../../enterprise/waf/incidents.md) page.

#### **Solution**

**Steps to Solve**:-

1. Go to [**Web Policy**](../../enterprise/waf/listener/profiles/policy/web_policy.md) and configure **Restricted File Upload** with the file extensions that should be blocked for uploads on the web application. By default, WAF blocks common dangerous extensions; adjust the list to match your application's requirements.

![kb-1008](/img/waf/v8/kb/kb_1008_web_policy.png)
![kb-1008](/img/waf/v8/kb/kb_1008_web_policy_condition.png)

2. For upload forms that need finer control, create a [**Form Rule**](../../enterprise/waf/listener/profiles/rules/form_rules.md) on the submission URI. Under **Field Validation**, set **Allowed File Extension**, **Min File Size**, and **Max File Size** for the upload field. This permits specific file types on trusted forms while global restrictions remain in place elsewhere.

3. Set the maximum upload size in **Maximum HTTP Body Size** on the [**Operational Settings**](../../enterprise/waf/listener/Setting/operational.md) page. Requests exceeding this limit are dropped. The default is 10 MB (10485760 bytes).

![kb-1008](/img/waf/v8/kb/kb_1008_operational.png)

4. Enable [**Antivirus**](../../enterprise/waf/listener/profiles/anti_virus.md) scanning on the security profile. Use **Internal** mode for Haltdos built-in scanning, or **External** mode to forward uploads to an ICAP-compatible antivirus server.

![kb-1008](/img/waf/v8/kb/kb_1008_antivirus.png)

5. Review blocked upload attempts on the **Incidents** page. Malicious or policy-violating files are dropped before they reach the backend application.
