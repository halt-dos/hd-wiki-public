# Incidents

Dropped and recorded rule matches, upstream errors and server health changes.

---

### Overview

Incidents lists the events that affected your endpoints. Filter them by category using the tabs.

| Category | Description |
| --- | --- |
| **Drop** | Requests that were dropped |
| **Record** | Requests that matched a rule and were recorded |
| **Error** | Errors returned by the upstream servers |
| **Health** | Changes in the health of a server |

![Incidents](/img/apid/incidents.png)

### How to Use:

1. Go to **Stack** > **APID** > **Incidents**.
2. Select an **Endpoint** and the time range.
3. Select a category, or search by incident ID, IP address or URI.

The table shows the incident ID, timestamp, category, server or domain and a summary. It can be exported.
