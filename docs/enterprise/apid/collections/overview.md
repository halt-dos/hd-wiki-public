# Overview

A summary of the APIs and risks of a collection.

---

### Overview

The Overview page gives a quick picture of a collection.

![Collection Overview](/img/apid/collection_overview.png)

### How to Use:

1. Go to **Stack** > **APID** > **Collection** and select a collection.
2. Open the **Overview** tab.

| Section | Description |
| --- | --- |
| **Endpoints** | Total number of APIs of the collection, and how many of them are authenticated, unauthenticated or of unknown authentication |
| **Risk** | The APIs grouped by risk: Critical, High, Medium, Low and None |
| **Top methods** | The most used HTTP methods in the collection |
| **Top vulnerabilities** | The most serious dependency vulnerabilities. Click **View all findings** to open [Findings](./findings.md). |

The numbers come from the latest scan of the repository. Run a scan from [Settings](./settings.md) if the page is empty.
