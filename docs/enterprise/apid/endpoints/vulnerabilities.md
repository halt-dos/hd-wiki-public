# Vulnerabilities

Vulnerabilities found by scanning an endpoint.

---

### Overview

The Vulnerabilities page shows the DAST alerts raised by the vulnerability scans of the endpoint. Scans are configured and scheduled in [DAST Scan](./dast_scan.md).

### How to Use:

1. Go to **Stack** > **APID** > **Endpoints** and select an endpoint.
2. Open the **Vulnerabilities** tab.

![Vulnerabilities](/img/apid/vulnerabilities.png)

Each finding shows its severity, the alert name, the URL, the scan target, the finding details and the scan run that found it. If the list is empty, configure and run a scan in [DAST Scan](./dast_scan.md). The list can be exported to CSV. PDF reports of the completed scans of all endpoints are available in [Reports](../reports.md).
