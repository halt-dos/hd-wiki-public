# Overview

This page displays configurations of the Stack, like Info, Instance Mapping, Members, Limits.

---

## Info

![Stack Overview](/img/platform/v8/docs/stackOverview.png)

It displays Stack ID, Stack Name, Created Date, Expiry, Status, Throughput, State and Type of the Stack.

---

## Instance Mapping

![Instance Mapping](/img/platform/v8/docs/stackInstanceMapping.png)

It displays Instance ID, Apps and Stack Type.

---

## Members

![Members](/img/platform/v8/docs/stackMembers.png)

It displays Member name, username, email, role (READ / READ_WRITE / ADMIN), login mode and action.

---

### Action

1. In Member Information, we can edit name, email, enable login or not, enable notification or not, stack permission (Admin / Read & Write / Read Only / Visible).

![Member Info](/img/platform/v8/docs/stackMemberEdit.png)

2. In Custom Permissions, we can change Resource, Access (Admin / Read & Write / Read Only / Visible), Enable Notification or not, and click on Add Permission.

![Custom Permission](/img/platform/v8/docs/stackMemberPermissionEdit.png)

3. We can Update / Reset Password by clicking on the Lock Icon.

![Member Update Password](/img/platform/v8/docs/stackMemberUpdatePass.png)

4. We can delete or add a new member.

---
