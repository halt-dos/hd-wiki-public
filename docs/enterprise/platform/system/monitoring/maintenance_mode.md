# Maintenance Mode

---

This is the Maintenance page, notification to a user can be sent from here. 

![Maintenance](/img/platform/v8/docs/sysMonitorMaintenance.png)

### How to Use:

1. Go to **System > Monitor > Maintenance**.
2. Configure your settings
3. Click **Save Changes**
