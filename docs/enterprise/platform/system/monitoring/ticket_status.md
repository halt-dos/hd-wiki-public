# Ticket Status

---

This is the Ticket Status page, status of all Ticekts can be monitored from here. Displays Title, Status, Created By, Tags, Last Updated By of each Ticket available.

![Tickets Status](/img/platform/v8/docs/sysMonitorTickets.png)

### How to Use:

1. Go to **System > Monitor > Job Status**.
