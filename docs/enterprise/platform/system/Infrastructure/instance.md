# Instance

---

This Instance page shows the list of instances

![Analytics](/img/platform/v8/docs/sysInstance.png)

### Description

#### **Name**

Enter the name of the instance

```
    Accepted Value: String

    Default: Blank
```


#### **Type**

Select the type

```
    Accepted Value: MITIGATION / MANAGEMENT

    Default: MITIGATION
```


#### **Category**

Select the Category

```
    Accepted Value: WAF / DNS / CDN / SCAN / SLB

    Default: SLB
```


#### **Cluster**

Select the Cluster ID

```
    Accepted Value: String

    Default: Empty
```
