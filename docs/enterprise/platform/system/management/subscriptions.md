# Subscriptions
Shows list of all Apps subscribed by each Stack. The Subscription section shows the list of stacks with there Stack Name, Stack ID, and APP. 

![Subscriptions](/img/platform/v8/docs/sysMgmtSubscriptions.png)

**How to Use:**

1. Go to **System** > **Management** > **Subscriptions**
