# User Permissions

Shows the permission allowed for listed users. The permission section shows the list of selected users with there Username, Email, and Access Type (Admin / Read / Read_Write) 

![User Permissions](/img/platform/v8/docs/sysMgmtUserPermission.png)

**How to Use:**

1. Go to **System** > **Management** > **Permission**
