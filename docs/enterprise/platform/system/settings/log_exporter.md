# Log Exporter

### Configure the log exporter period for the Haltdos appliances

---
This feature allows users to set the log Exporter configuration. The Log Exporter exports logs for specific Stack and respective Resource within some time frame.

:::info
Log exporter should be configured as per organization policy
:::

![Log Exporter](/img/platform/v8/docs/log_exporter.png)

### How to Use:

1. Go to **System > Settings > Log exporter**.

2. Configure your settings.

3. Click **Save Changes**.

### Description:

##### **Stacks**

This option allows users to specify the Stack.

```
    Accepted values: Stack Name

    Default: Empty
```


##### **Resource**

This option allows users to specify the respective Resource.

```
    Accepted values: Resource Name

    Default: Empty
```


##### **Date Range**

This option allows users to specify the date range which logs are to be downloaded.

```
    Accepted values: Date Range

    Default: Empty
```
