# Groups

Configuring Groups in Haltdos IPAM

---

The **Groups** section in IP Address Management **(IPAM)** allows users to logically organize and manage multiple networks under a single unit. Grouping networks simplifies administration, enhances visibility, and supports large-scale infrastructure management by associating related networks based on site, department, or function.


![operational](/img/plugins/ipam/groups.png)

---
### Description

##### **Group Name**  
Specify the name of the group. Each group should have a unique and meaningful name to represent its purpose or associated site.

```
Accepted Value: String

Default: None
```
